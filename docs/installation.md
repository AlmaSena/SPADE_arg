# Installation

## Stable release

To install SPADE-argumentative, run this command in your terminal:

```sh
uv add SPADE_arg
```

Or if you prefer to use `pip`:

```sh
pip install SPADE_arg
```

## From source

The source files for SPADE-argumentative can be downloaded from the [Github repo](https://github.com/AlmaSena/SPADE_arg).

You can either clone the public repository:

```sh
git clone https://github.com/AlmaSena/SPADE_arg
```

Or download the [tarball](https://github.com/AlmaSena/SPADE_arg/tarball/main):

```sh
curl -OJL https://github.com/AlmaSena/SPADE_arg/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd SPADE_arg
uv sync
```
